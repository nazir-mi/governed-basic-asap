# Data availability and repository citation

The manuscript uses one Data Availability Statement rather than a separate Supplementary Materials section. It links to the exact public repository commit supporting the submission. The repository supplies selected research materials, not unrestricted access to all source data or every external-analysis output.

Suggested statement, with the submitted commit identifier added in the manuscript:

> Analysis code, output-free notebooks, slice-registry metadata, methodological documentation and selected non-RIPAS aggregate result tables are publicly available in the versioned repository at https://github.com/nazirkaoje777-dotcom/governed-basic-asap. The repository includes reproduction instructions, a file manifest and a manuscript output map identifying supporting files and exclusions. Kaggle and NHAMCS source records must be obtained independently from the original providers. Patient-level records, cleaned encounter-level derivatives, individual predictions, fold assignments, profile hashes and slice-membership matrices are not redistributed. RIPAS data and derived result files are not supplied through GitHub and remain subject to institutional and data-custodian restrictions; requests must be directed to the corresponding author and require applicable permissions and approvals.

Do not describe this collection as a complete public dataset or a fully reproduced manuscript. Add an archival DOI or open-source licence only after it has actually been issued and the applicable rights have been confirmed.
