# Analysis scripts

The scripts implement discovery comparisons, governed repair, held-out evaluation
and external validation. Run them from the repository root after constructing
the required inputs.

See the [run guide](../Documentation/RUN_GUIDE.md) for script dependencies and
the [attribute-free protocol](../Documentation/ATTRIBUTE_FREE_CORRECTION.md)
for the shared-fold comparison in `attribute_free/`.

Source data and encounter-level runtime outputs belong in the ignored local
directories specified by the scripts, rather than in the public repository.
