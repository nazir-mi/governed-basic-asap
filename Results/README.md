# Aggregate results

Results are organized by analysis stage. Use the
[manuscript output map](../Documentation/MANUSCRIPT_OUTPUT_MAP.csv) to locate
the files corresponding to each table and figure.

`attribute_free_corrected/` supplies the fixed-registry robustness comparison
in Table 12 and Figure 8. `attribute_free_historical/` contains a superseded
comparison and the separate concealed-rule construct-validation summary used
in Figure 9. These analyses answer different questions and must not be pooled.

CSV tables report group-level or model-level results. Data access for analyses
requiring institutionally controlled inputs is described in
[DATA_SHARING.md](../Documentation/DATA_SHARING.md).
